事件归并设计 v1.5

把指向同一件真实事情的多次提及归到一起，得到事件表。只回答“这些提及说的是不是同一件事”：不判断谁对谁错（工序4），也不把事件串成治疗线（工序5）。

输入

工序2 的提及表：原文、类型与细分、发生时间区间、写成时间、阴性、模板化、动作。
→

输出

事件表（一行一个事件）＋提及→事件映射表（一行一条提及）。

事件形态

先定事件是什么形态，才知道怎样算“同一个”。

形态含义示意
点事件发生一次，有一个时间点或区间一次检验结果、一次手术、一次入院、一次停药、某次就诊时的一项查体发现
片段持续一段，有起止一次发病的气急从“3天前”到入院后好转；一段“文书称在用”的用药期
状态被反复声明仍成立，只记首见与末见某诊断、某病史否认、家族史
一次性一生只会发生一次，不看时间直接合并开始维持性透析、子宫切除、初潮
就诊（容器）一次住院／门诊／检查；不是医疗事件本身，但每条提及都挂到所属就诊，作为归并约束住院 3 月 4 日–3 月 9 日；某日门诊

归并原则

  • 只在同类型（事实／判断／决策）、同细分内归并；跨类型的关系留给工序5。
  • 必须是同一概念：先按词表把别名归一，归一不了的不合并。
  • 时间要相容，容差按精度定；只会发生一次的概念例外。
  • 逐字复制的同一句话指同一件事，即使按成文日推算出的日期已经漂移。
  • 归并不改原文，也不挑选“正确”的版本；有冲突也照样归入，冲突交工序4。

规则顺序

从上往下，命中即停。

顺序规则做法
1结构化对齐文书提及与结构化记录同概念、同值、同日 → 并入结构化事件
2逐字复制同一句（逐字相同）出现在多份文书，且这句话本身带时间（或属诊断、用药这类状态）→ 指同一事件，不论推算日期是否漂移；不带时间的套话（如“活动后偶有气急”）不算
3一次性概念只会发生一次的概念 → 不论时间直接合并，时间冲突留给工序4
4同概念＋时间相容＋同就诊按上表各概念组的判定键与时间约束
5同句修饰并入症状后面紧跟的、本身不含症状词的描述性分句（如“按之呈凹陷性”“休息后可略缓解”）并入同句的（阳性）症状事件；带“查／示：”的检验检查分句不并
6状态连续状态类提及按概念＋极性合并；用药按间隔与“停止”断段
7单提及以上都不满足 → 自成一个事件

背景状态内容（归一）不看时间家族史、个人史、月经婚育史在不同文书里的重复记载合并
病史否认状态病名（归一）＋否认不看时间模板化否认合并为一个“否认×”状态
其他单提及——没有归一到任何概念的提及，各自单独成事件，标“未归一”；词表外的检验项目按原项目名归一，带病名的病情评估按诊断处理

用药片段怎么断

同一药的“在用”提及按时间排序，相邻两次间隔 ≤180 天且中间没有该药的“停止”点事件，就连成一段；否则断开。180 天只是本工序的断段口径，不代表实际停药：间隔内若出现另一种不能同时使用的药（见互斥用药组），本工序不改片段，由工序4 判为“互斥用药并存”的矛盾。

互斥组药物说明
口服抗凝药华法林、利伐沙班维生素K拮抗剂与直接口服抗凝药通常不联用；换药时有短暂重叠属正常，重叠超过换药窗口才算矛盾，窗口由工序4定。

交给工序4 的线索

本工序只标记，不判断对错。

线索含义
时间不一致同一事件内各提及的发生区间没有交集，例如一次性事件的几种日期。
互斥用药并存互斥组内两种药的在用片段时间重叠。
互斥用药先后出现（缺停用记载）互斥组内 B 药启动后没有 B 的停用记载，之后又出现 A 药在用记载；不推断 B 是否仍在用，只提示工序4。
候选同义相关但不同名的诊断（见“刻意不合并的”），列出各自首见、末见。
阴阳并存同一概念同时有阳性状态与“否认”状态，例如某诊断与“否认某诊断”。

刻意不合并的

这些看起来像同一件事，但本工序不合并。

对象理由
尿毒症／慢性肾脏病5期／慢性肾衰竭／慢性肾衰临床上相关、常被混用，但不是同一诊断名；不合并，记为“候选同义”，由工序4与医生判断。
中医证候（脾肾气虚证、风热犯肺证…）与西医诊断体系不同，不合并。
心功能Ⅲ级／Ⅳ级、慢性肾脏病4期／5期分级或分期不同即不同诊断状态，不合并；变化交工序4判“改判”。
检验的不同方法学（如超敏肌钙蛋白与肌钙蛋白T）只有数值完全相同（多为文书转抄同一结果）时才合并。

示意

下列例子用来说明规则，不是某个患者的记录。

情形例子处理
同一次检验在两处出现入院记录“（3月3日本院）钾 5.30mmol/L”＋检验表 3月3日 钾 5.30结构化对齐 → 一个事件
同一句被抄进多份文书“10年前行子宫切除术”出现在 2017、2020、2024 年三份入院记录逐字复制＋一次性 → 一个事件；推算日期漂移交工序4
同一次发病的多次描述入院记录“3天前出现气急”、出院记录“因‘胸闷气急3天’入院”同概念＋同就诊 → 一个片段
不同次发病2024 年 3 月与 10 月两次住院都有“气急”就诊不同 → 两个片段
同一诊断被反复记录诊断表里 150 次“血液透析”状态 → 一个事件，记首见与末见
相关但不同名“尿毒症”与“慢性肾脏病5期”不合并，记候选同义
用药被反复提到三次门诊都写“长期服用某药”，中间无停药，间隔都 <180 天状态连续 → 一个用药片段
停药后再用某药“暂停” → 两周后“恢复”停止点 → 断成两段，另有一个停止点事件

校验与验收

  • 每条提及恰好属于一个事件；事件内所有提及类型相同。
  • 两条结构化记录不会因归并合成一个事件（除非完全重复）。
  • 归并不改原文、不挑“正确版本”：冲突的提及可以在同一事件里，冲突本身交工序4。
  • 每版规则改动后抽样核对：随机 50 个多提及事件，人工看是否真是同一件事；随机 50 个单提及事件，看是否漏并。

待验证问题

下一批病例重点看这些。

  • 症状与查体只在同一次就诊内合并，跨就诊仅逐字复制可并——首个病例试运行后复核漏并情况。
  • 互斥用药“换药窗口”多长算正常重叠，由工序4 定。
  • 商品名→通用名映射待药师复核。
  • 引号里以空格分隔的整串诊断（如“慢性肾脏病5期 肾性贫血 血液透析…”）目前当成一个诊断名，未拆开。
