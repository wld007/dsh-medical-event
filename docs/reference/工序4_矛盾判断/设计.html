工序 4 / 8

矛盾判断设计 v1.0

在工序3 的事件上判断冲突是什么性质：是记录错了（矛盾），是认识更新了（改判），是方案变了（调整），还是病情本来就在变。不删改原文，也不替医生下结论；判不了的就写“证据不足”。

输入

工序3 的事件表、提及→事件映射，以及工序3 交来的线索（时间不一致、互斥用药、候选同义、阴阳并存）。
→

输出

发现表：一行一个冲突，列出各方原文与来源等级、判定、命中规则、建议采信与确定程度。

原则

  • 不删、不改原文；矛盾的各方原样保留。
  • 不替医生下诊断：只说“这两条不能同时成立”，不说“真实情况是什么”。
  • “证据不足”是合法结论，不强行归类。
  • 记录质量问题（模板、复制、补写）与临床上的矛盾分开报。
  • 每条发现都能追溯到工序1 的原始提及。

判定结果

每个冲突最终落到这七类之一。

判定含义典型情形
矛盾同一时点、同一对象的两条记录不可能同时成立事实×事实；或同一时期的阳性与否认；或互斥药同期在用且无换药记载
改判对同一对象的判断随后来的证据改变判断×判断，后一判断针对的是前一判断所指的同一发现
调整方案变化，并且原文记载了变化决策×决策，中间有停用、改用、减量等动作
病情变化不同时点状态不同，本来就会变分期、分级、数值随时间变化；不进矛盾表，只记一笔
命名不一致相关但不同名的说法并存候选同义诊断；交医生确认是否同指
记录质量冲突来自写法而非临床：模板未改、复制漂移、版本补写例如模板化否认与阳性诊断并存；仍逐条列出
证据不足有冲突迹象但材料不足以判断合法结论，不强行归类

子类

判定子类含义
矛盾时间矛盾一次性事件或同一事件有互不相交的日期
矛盾数值矛盾同一次检验或同一时刻体征出现不同数值
矛盾存在矛盾同一时期既记有又记无（阳性与否认）
矛盾用药矛盾互斥药同期在用超过换药窗口，且无停用／改用记载；或停用后仍记在用而无恢复记载
矛盾文书内自相矛盾同一份文书里两句互相否定
矛盾版本冲突同一次就诊的两版文书说法不同
记录质量转述误差回顾转述与同期记录不一致，以同期为准
记录质量复制漂移同一句带相对时间的话被抄进不同日期文书，推算日期随之漂移
记录质量模板化否认否认来自重复模板，与阳性记录冲突

规则（按顺序）

从上往下判，命中即停。

规则做法
R1 时间先行只比较时间上可能重叠的记录；不同时点的不同值先归“病情变化”，不当矛盾
R2 按类型配对事实×事实→矛盾候选；判断×判断→改判候选；决策×决策→调整候选；跨类型不直接判矛盾
R3 一次性事件多日期判时间矛盾；若各日期能用复制漂移或回顾转述解释，再标对应的记录质量子类
R4 阳性与否认并存同一时期既有阳性又有否认：否认来自模板化内容→记录质量·模板化否认；否则→矛盾·存在矛盾
R5 互斥用药两药在用片段重叠超过换药窗口、且无停用或改用记载→矛盾·用药矛盾；有改用记载且重叠在窗口内→调整
R6 停用后仍记在用某药有停用记载，之后又记在用，中间没有恢复记载→证据不足（可能恢复用药也可能是复制）
R7 同对象判断改变同一检查对象（如某部位影像发现）的结论在后续检查中改变→改判候选，需人工确认
R8 文书内与版本冲突同一份文书内两句互斥→文书内自相矛盾；同一就诊两版文书不同→版本冲突
R9 候选同义相关不同名诊断并存→命名不一致，不判矛盾
R10 兜底以上都判不了→证据不足

来源可信度

用于给出“建议采信”，不用于删除。级别相同时标“需人工确认”。

级别来源说明
1结构化记录检验、诊断、手术、收费等系统字段
2同期文书就诊当时写成的文书
3同次补记属本次就诊但晚于 14 天写成
4回顾转述后来文书里对以前的转述
5外院转述本院文书转述的外院情况
6模板化内容模板否认、逐字复用的套话

情形例子判定

诊断与否认并存诊断表多次记某病，入院记录既往史模板“否认某病”记录质量·模板化否认（或待定为矛盾）

待验证问题

下一批病例重点看这些。

  • 影像改判目前只看“同一对象、前一次带不确定措辞、发现名词改变”，可能漏掉措辞不同的改判。
  • 数值矛盾只查“文书写明日期的检验值”与同日检验表；同日多次采样（如透前透后）时可能误报，需人工确认。
  • 上位概念表（脑血管病⊇脑梗死等）需医生补充。
