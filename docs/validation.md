采纳老结果的做法（新版起初做错）：
- 年龄换算按生日（满 N 岁那一年），不是日历年。
- 第二版入院记录的查体、时间副词按文内记录时间，不是保存时间。
- 出院记录“入院情况”里化验行的行首日期可同行继承；但只继承**行首日期**，叙述句不继承。
- 同一句有多个时间短语时取最精确的（“2年余前（2017.10）”取 2017.10）。
- “起初”沿用上文整个区间，不收缩成点。
- “血透2年”：起点在 3～2 年前（满 N 年不足 N+1 年）。

新增修正：“一周三次”“每周3次”是频次，不再当作病程。

## S03 类型切分

对照方式：按“记录类型＋栏目＋原文”配对老结果的文书提及（14,469 条），比较类型、细分、细项。

| 项 | 结果 |
|---|---|
| 类型一致 | 99.9% |
| 细分＋细项一致 | 97.9% |
| 类型分布（新） | 事实 14,906／判断 5,726／决策 5,128（老 15,155／5,106／5,148） |
| 兜底（Z2、Z9）命中率 | 5.4%（老 Z2 807 条，约 5.3%） |

更正：设计里的 3% 指抽样人工核对的**错误率**，不是兜底命中率。验收门②只报兜底命中率，抽样核对由人做（复核页面）。

采纳老结果的做法：
- “新冠疫苗接种”“体质”归背景（设计 v2.1）。
- 个人史栏目里的否认（冶游、烟酒）走“病史否认”，再按词表落到背景›过敏与接触史；只有非否认的个人史内容才是“病史栏目·其他”。
- 阴性查体只在查体语境（查体栏目、同一句前文有“查体”、出院记录入/出院情况里的查体用语）；现病史里的“无皮疹”是症状。
- 处理意见里的检查项目名（生化、CRP、心超……）是复查与随访；“X科随诊/复诊”是转诊。
- “入院后予以…”是治疗，不是就医经过；“已停”是停用；“调整生活方式”不是方案调整。
- 生命体征允许“呼吸：18次/分”这种带冒号写法。
- 影像所见按同一句前文判断（“胸部正侧位：心影增大，双侧胸腔积液”）。

新版更好、保留：
- “无尿频尿急尿痛”是阴性（老的“无尿”假阴性规则太宽）。
- 处理意见的“血PTH”“胸片”是复查与随访，“补充蛋白质”是生活方式与宣教（老结果对检查项目名前后不一致）。
- “心功能Ⅲ级”是病情评估（设计示例）；心电图所见归影像／心电／超声。

语境范围：只看同一句（句号或换行之前），看整行会把前一句的“CT”带进来。
